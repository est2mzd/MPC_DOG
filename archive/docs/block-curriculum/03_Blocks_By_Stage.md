# フェーズごとに生きる関数

進める順番の正本は [00](00_README.md) である。本章は、どのフェーズでどの関数を呼ぶかの一覧である。

## 1. 結論

全部のクラスを先に作らない。**今のフェーズで呼ばれるものだけ** を書く。  
呼び出しの形は S1 で決め、中身は後から足す（[00](00_README.md) §3.1）。

記号:

- **○** このフェーズで使う（新規または継続）
- **☓** まだ足さない

## 2. フェーズ 0 — 共通の式（現象 S0–S4 とごく遅い前進）

予測最適化・WBC・KF・着地点の先送り・地形推定は ☓。

| 現象 | Plant | clip | 接地 | EqualShare | MapJT | 高さ | Gait | Swing | vx | 着地 |
|---|---|---|---|---|---|---|---|---|---|---|
| S0 プラント | ○ | ○ | ☓ | ☓ | ☓ | ☓ | ☓ | ☓ | ☓ | ☓ |
| S1 静止 | ○ | ○ | ○ 1111 | ○ | ○ | ☓ | ☓ | ☓ | ☓ | ☓ |
| S2 高さ | ○ | ○ | ○ | ○ | ○ | ○ | ☓ | ☓ | ☓ | ☓ |

## 3. フェーズ 1 — LC が厚い中身

フェーズ 0 の ○ はすべて継続する。消さない。中身は **一つずつ** 足す（[00](00_README.md) §7）。

| 関数 | フェーズ 0 | フェーズ 1 で足す |
|---|---|---|
| 今の状態 | シミュレータ真値 | 線形 KF。真値は残す |
| 胴体の参照 | 高さ・速度の定数 | 現在と最大 1 秒先の 2 点 |
| 脚力を決める | EqualShare | LC の NMPC。EqualShare は残す |
| 力 → トルク | MapJT | WeightedWbc。MapJT は残す |
| 関節指令 | トルク飽和 | ハイブリッド（Kp=0, Kd 固定, ff=τ） |
| 着地点 | 今の xy | 増やさない |
| 床 | 水平 | 増やさない |
| 速さ・地形 | ごく小さい vx まで | ☓ |

NMPC と WBC を、同じ週にどちらも初めて比較しない。

## 4. フェーズ 2 — PyMPC が厚い中身

フェーズ 1 までの実装は残す。

| 関数 | フェーズ 1 まで | フェーズ 2 で足す |
|---|---|---|
| 参照 | 2 点（LC） | HoldVelocity（水平位置は追わない）。2 点は残す |
| 着地点 | 今の xy | 速度と立脚時間から先へ置く |
| 床 | 水平 | 傾きの推定、必要なら速度の変調 |
| 脚力を決める | EqualShare と LC NMPC | 短い単剛体 + acados。前の二つは残す |
| 力 → トルク | MapJT と WBC | フェーズ 0 の MapJT を PyMPC 経路で使う。作り直さない |
| sampling / lyapunov | ☓ | nominal がログに並んでから |

## 5. フェーズ 3 — 速さ・地形（新しい層は足さない）

既存の関数の中身を厚くする。一度に動かす軸は1つ（[11](11_Difficulty_Map.md)）。

| 段 | 主に厚くなるもの | 同時に変えない |
|---|---|---|
| 速さ V | \(v\), \(f\), \(d\), 水平力、摩擦 | 地形 |
| 坂 | 床の傾き、指令の回転、斜面摩擦 | 地面の欠け、高速 |
| 凸凹 | 遊脚の高さ、着地 z | 欠けの回避、高速 |
| 地面の欠け | 着地点を乗ってよい点へ | 高速、bound |
| 混ぜ | 既存の組み合わせ | 新しい層 |

脚力の比較相手は、フェーズ 1 の NMPC とフェーズ 2 の acados である。EqualShare は残す。高速の主プランナにはしない。

## 6. 方針 — 実装する順（ファイル）

上流の切出し順ではなく、[00](00_README.md) のフェーズ順である。

1. `plant` + トルク飽和
2. 型（接地フラグ, `Grf`）と合力のテスト（数字だけ、sim なし）
3. `MapJT` のテスト（既知の J と F）
4. `EqualShare` + S1 ループ
5. 高さ（S2）
6. `PeriodicGait` 単体テスト（位相と \(c_i\)。ロボットなし）
7. `SwingPath` 単体（軌道がベル型になる）
8. S3 ループ（足踏み）
9. ゲイトの数値表（S4）。制御コードを増やさない
10. ごく小さい vx。着地は今の xy
11. フェーズ 1: KF → レート分離 → LC NMPC → WBC → ハイブリッド（一つずつ）
12. フェーズ 2: 参照 → 着地点先送り → 地形 → acados（一つずつ）
13. フェーズ 3: \(v\) だけ上げる → \(f\) を合わせる（[08](08_Speed_Ladder.md)）。坂・凸・欠けは別系列（[10](10_Slopes.md)、[09](09_Holes_and_Bumps.md)）
14. 最後に中速 × 一つの地形。そのあと凸凹坂

6 と 7 はロボットなしで理解できる。速さの \(v=fL\) もロボットなしで数字が書ける。

## 7. 方針 — 高さは脚力の中に隠さない

高さ P を `EqualShare` の中に隠すと、予測最適化に差し替えたとき高さが消える。  
`HeightRef` は参照側（\(z^{ref}\)）に置き、等分も NMPC も acados もそれを読む。

S2-A（関節しゃがみ）は参照でも力でもない別経路である。比較実験には使わない。理解用の脇道である。
