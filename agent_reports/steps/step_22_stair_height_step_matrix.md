# 日本の階段寸法に合わせた高さと段数の階段行列

## 第1章 概要

- Step 22は、基礎条件と日本の階段を参考にした3寸法を使い、段数5条件の上り下りを同じプログラムで比較する
- 基礎条件は、高さ 0.10 mと踏面奥行き 0.35 mを組み合わせる
- 日本の階段寸法は、高さと踏面奥行きを 0.15 mと 0.30 m、0.18 mと 0.26 m、0.20 mと 0.24 mの組にする
- 段数条件は2段、4段、6段、8段、10段である
- 各worldは指定段数を上り、奥行き 1.00 mの最上面を通り、同じ段数を下り、退出平地へ続く
- 高さ 0.10 m系列は、2段、6段、8段、10段に成功し、4段に失敗した
- 高さ 0.10 mの4段失敗は、3段目の踏面まで進んだあとピッチが崩れ、段数限界ではない
- 高さ 0.15 mと踏面奥行き 0.35 mの2段は、1段目の踏面でロールが崩れて失敗した
- 高さ 0.15 mと踏面奥行き 0.30 mの2段は階段上で転倒せず、退出平地でヨーが -0.59 rad まで増えた
- 高さ 0.15 mと踏面奥行き 0.30 mの4段、8段、10段は上りまたは最上面で転倒し、6段は下り始めの蹴上で転倒した

## 第2章 共通設定

### 概要

- 全条件は、同じRelease overlayと同じインストール済みyamlを使う
- 全条件は、速度 0.10 m/sとクロール歩容を使う
- 日本の階段寸法は、蹴上と踏面奥行きの組を変え、傾斜角も同時に変える
- 各条件は、段数に応じて速度指令時間と固定カメラ範囲だけを広げる
- 成功判定は、下り終端から1.50 m以上先へ進み、終了時に胴体が直立することを要求する
- 各条件は、CSV、mp4、GIF、run logを同じ記録名へ保存する

### 詳細

- 全条件は、同じRelease overlayと同じインストール済みyamlを使う
  - overlayは `/tmp/mpc_dog_stack_release_install/setup.bash` である
  - `multistep_planner.enabled` と `apply_stop_request` は真である
  - `apply_foothold` は偽である
  - 足先支持と厳密IKは `shadow` である
  - 振り足地形判定は `enforce` である
- 全条件は、速度 0.10 m/sとクロール歩容を使う
  - 最初の蹴上は x=3.00 mである
  - 初期胴体 xは 1.00 mである
  - 上り段数と下り段数は同じである
- 日本の階段寸法は、蹴上と踏面奥行きの組を変え、傾斜角も同時に変える
  - 緩やかな階段は、高さ 0.15 mと踏面奥行き 0.30 mを使い、傾斜角を約26.6 degにする
  - ビルやマンションの共用階段は、高さ 0.18 mと踏面奥行き 0.26 mを使い、傾斜角を約34.7 degにする
  - 住宅内階段は、高さ 0.20 mと踏面奥行き 0.24 mを使い、傾斜角を約39.8 degにする
  - 高さ 0.16 mと踏面奥行き 0.30 mは、緩やかな階段との差が小さいため初回行列から外す
  - 高さ 0.22 mと踏面奥行き 0.21 mは、傾斜角が約46.3 degになるため3系列の後に追加難度として扱う
- 全条件は、上りから下りへ向きを変える最上面の奥行きを 1.00 mにする
  - 最上面は通常の踏面と区別し、Go2が上り姿勢から下り姿勢へ移る水平区間にする
- 各条件は、段数に応じて速度指令時間と固定カメラ範囲だけを広げる
  - 2段は70秒である
  - 4段は90秒である
  - 6段は110秒である
  - 8段は130秒である
  - 10段は150秒である
- 成功判定は、下り終端から1.50 m以上先へ進み、終了時に胴体が直立することを要求する
  - 終了時の胴体 zは 0.20 mより大きくする
  - 終了時のロールとピッチの絶対値は 0.50 radより小さくする
  - 最大 xは `exit_x + 1.50 m` 以上にする
- 各条件は、CSV、mp4、GIF、run logを同じ記録名へ保存する
  - 数値一覧は `artifacts/logs/step22_stair_matrix_summary.csv` に保存する
  - GIFは各 `quadsdk_step22_*` ディレクトリの `trial.gif` に保存する

## 第3章 生成コマンドと実行コマンド

### 概要

- 地形生成は、日本の階段寸法3条件と段数5条件の15 worldを作る
- worldのインストールは `quad_sim_scripts` を一度だけRelease overlayへ構築する
- 高さ系列の実行は、行列実行スクリプトへ高さコードを渡す
- 最初の高さ系列は、引数の使用法文字列が末尾へ `}` を加えたため、試行開始前に一度失敗した

### 詳細

- 地形生成は、高さ3条件と段数5条件の15 worldを作る

```bash
for spec in 15:0.15:30:0.30 18:0.18:26:0.26 20:0.20:24:0.24; do IFS=: read -r hcode height dcode tread <<< "$spec"; for steps in 2 4 6 8 10; do name=$(printf 'jp_stair_matrix_h%s_d%s_n%02d' "$hcode" "$dcode" "$steps"); python3 src/trial/assets/gen_quadsdk_stair_curriculum.py --name "$name" --riser "$height" --tread "$tread" --steps "$steps" --top-run 1.00 --exit-run 3.00; done; done
```

- worldのインストールは `quad_sim_scripts` を一度だけRelease overlayへ構築する

```bash
source /opt/ros/jazzy/setup.bash && source ros2_ws/install/setup.bash && source /tmp/mpc_dog_stack_release_install/setup.bash && colcon --log-base /tmp/mpc_dog_stack_release_log build --base-paths external/quad-sdk --packages-select quad_sim_scripts --build-base /tmp/mpc_dog_stack_release_build --install-base /tmp/mpc_dog_stack_release_install --cmake-args -DCMAKE_BUILD_TYPE=Release -DPYTHON_EXECUTABLE=/usr/bin/python3 -DPython_EXECUTABLE=/usr/bin/python3 -DPython3_EXECUTABLE=/usr/bin/python3
```

- 高さ 0.10 m系列は、高さコード10を渡して実行する

```bash
QUADSDK_OVERLAY_SETUP=/tmp/mpc_dog_stack_release_install/setup.bash bash scripts/trial/run_quadsdk_stair_matrix.sh 10
```

- 高さ 0.15 m系列は、高さコード15を渡して実行する

```bash
QUADSDK_OVERLAY_SETUP=/tmp/mpc_dog_stack_release_install/setup.bash bash scripts/trial/run_quadsdk_stair_matrix.sh 15
```

- 高さ 0.18 m系列は、高さコード18を渡して実行する

```bash
QUADSDK_OVERLAY_SETUP=/tmp/mpc_dog_stack_release_install/setup.bash bash scripts/trial/run_quadsdk_stair_matrix.sh 18
```

- 高さ 0.20 m系列は、高さコード20を渡して実行する

```bash
QUADSDK_OVERLAY_SETUP=/tmp/mpc_dog_stack_release_install/setup.bash bash scripts/trial/run_quadsdk_stair_matrix.sh 20
```

- 最初の高さ系列は、引数の使用法文字列が末尾へ `}` を加えたため、試行開始前に一度失敗した
  - `${1:?usage: $0 {10|15|20}}` は引数10を `10}` として代入した
  - 使用法文字列を `${1:?usage: $0 HEIGHT_CODE}` へ変更した
  - 修正後は存在しないoverlayを与える検証で、引数10が高さ分岐を通ることを確認した

## 結論

- 高さ 0.10 m系列は5条件中4条件に成功した
- 高さ 0.10 mの10段成功は、奥行き0.35 mで連続する上り下りを継続できることを示した

- 高さ 0.18 mと 0.20 mの系列は未確認なので、日本の階段寸法に対する能力限界をまだ結論にしない
- 次の技術的な積み上げは、4段条件を反復し、足先支持判定だけを変更して成功率を比較することである
